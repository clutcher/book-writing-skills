# Glossary

The terms this book formally defines, with the book's own wording for each. The review-ideas skill seeds entries, the author writes the definitions, and the checks compare the manuscript with them. Format and rules: glossary-format.md in the plugin's lib folder.

## Entry format

```
### <term>{{separator}}<location> (<kind or attribution>)
**Canonical definition:** <the definition, in the book's own wording>
**Invariants:** <only when the term has a competing meaning the definition does not block>
```
