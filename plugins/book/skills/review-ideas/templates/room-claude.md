# Clean room for an outside review

This folder is a cold outside review of a book. Start with `REVIEW-PLAN.md` and follow it.

- Never edit `manuscript/`, `sources/`, `book/` or `decisions.md`. Write only inside `review/`.
- Do not look for the author's notes, research or earlier drafts outside this folder. Reviewers
  judge the book as a stranger meets it.
- Ask before every batch of agents.
