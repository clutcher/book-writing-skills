# Organizing a catalog of techniques or patterns

Many non-fiction books contain a catalog: patterns, techniques, mistakes, recipes. How the
entries are grouped and ordered decides whether readers can learn from it and find things in it.

## How well-known catalogs are organized

Catalogs from different fields use a small number of axes:

| Book | Main axis | Note |
|---|---|---|
| *A Pattern Language* (Alexander, Ishikawa, Silverstein) | scale: towns, then buildings, then construction | scale works here because each pattern belongs to one scale |
| *The Elements of Style* (Strunk and White) | kind of rule (usage, composition, form), then a list of misused words | a short catalog read front to back, with a lookup list at the end |
| *Salt, Fat, Acid, Heat* (Nosrat) | principle first (the four elements), then recipes as their applications | teaches understanding first, lookup second |
| A general cookbook such as *Joy of Cooking* | kind of dish (soups, breads, desserts) | built for lookup; the reader arrives knowing what they want to make |
| A first-aid manual | the reader's situation (bleeding, burns, choking) | matches how problems arrive; read under stress |
| A field guide to birds | family, then species, with a visual index | the index serves readers who cannot name the family yet |
| A garden encyclopedia | plant, then a season-by-task calendar | two axes crossed: what you grow and when you work on it |
| A home-repair manual | what you do to the material (cut, join, seal, finish) | adds a "learn these first" entry point for beginners |

## Axes and when each fails

| Axis | Best for | Fails when |
|---|---|---|
| Purpose or intent | reference; readers looking for a solution | one technique serves several purposes |
| Element or ingredient | "I am working with X; what applies?" | a technique spans elements |
| Kind of transformation | catalogs of changes (repairs, edits, preserving methods) | the reader cannot tell which one they need |
| Scale | entries that each belong to one scale | techniques that apply at several scales |
| Conceptual prerequisite | linear teaching | readers who want to look things up |
| Principle applied | teaching why patterns work | a large catalog |
| The reader's situation | teaching; matches how problems arrive | lookup, so add a flat index |
| Symptom or problem | diagnosis ("my bread has X") | many-to-many mappings |
| "Learn these first" | onboarding | it does not order the rest |

**Scale fails as the main axis for techniques that apply at several scales**, because every
entry lands in several groups. Catalogs that handle this use an axis orthogonal to scale
(purpose, element, transformation or principle) and show scale inside each entry, or separate "where"
(the levels) from "what" (the heuristics).

## What learning research says about entries

- **Spiral curriculum (Bruner):** return to a concept several times, each time at more depth.
- **Concreteness fading (Goldstone and Son):** start concrete, strip the details, arrive at the
  abstract idea, then apply it concretely again; this gives better transfer than either end
  alone.
- **Worked examples (Sweller and Cooper):** novices learn more from studied examples than from
  solving problems, so **open each technique with a concrete example**, not with its definition.
- **Interleaving (Bjork; Rohrer and Taylor):** mixing kinds of problems helps learners tell them
  apart. A book keeps coherent groups but adds comparisons ("is this problem A or problem B?").
- **Transfer (Barnett and Ceci; Gentner):** far transfer needs explicit bridging. After showing a
  technique in one setting, **name the structure that repeats** and show it in a second setting.
  **Two bridged examples beat five unbridged ones.**
- **Expertise reversal (Kalyuga):** support that helps beginners slows experts. Structure each
  entry so experts can skip the scaffolding (the principle stated early, the example after).

These findings come from studies of teaching in general, not of catalogs in books; apply them
as guides, not as measured rules for a catalog.
